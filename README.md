# Inventory Management

A windows app built with WPF for managing inventory. The app built with api of other project.

## Feature

- User authentication using JWT
- Read and Update Inventory.
- Pagination list of inventory.

## Installation

1. Clone the repository: `git clone https://github.com/Kruzk02/Inventory-Management.git `.
2. Navigate to the project directory: `cd Inventory-Management`.
3. Run project with this command: `dotnet run`.
